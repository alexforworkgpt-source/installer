# Issue Tracker

Issues, PRDs, specifications, and implementation tickets are stored as local Markdown files under `.scratch/`.

## Layout

Each feature or workstream gets its own directory:

`.scratch/<feature>/`

Use clear lowercase names separated by hyphens.

## Rules

- Read and write work items only inside `.scratch/`.
- Keep one Markdown file per issue, PRD, specification, or ticket.
- Use relative Markdown links between related files.
- Record dependencies explicitly in each ticket.
- Do not use GitHub or GitLab issue commands for this repository.
- Treat the files as the source of truth for work status.
