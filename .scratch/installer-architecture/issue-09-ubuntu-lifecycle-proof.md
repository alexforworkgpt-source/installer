# End-to-end доказательство lifecycle на Ubuntu 24.04

## Parent

[PRD: Безопасная и воспроизводимая установка Bedolaga Bot Stack](./prd.md)

## What to build

Доказать полный пользовательский lifecycle модернизированного installer в disposable Ubuntu 24.04 environment. Один воспроизводимый сценарий должен пройти clean-VPS preflight, свежую установку минимального профиля, повторную установку, settings draft и apply, compatible release update, injected failure и verified rollback, file recovery, functional health, non-root runtime и безопасный uninstall.

Это финальный tracer bullet всей программы: он проверяет взаимодействие опубликованных slices через их внешние интерфейсы и создаёт понятный release gate для будущих изменений installer.

## Acceptance criteria

- [x] Disposable Ubuntu 24.04 environment создаётся и очищается воспроизводимо.
- [x] Clean-VPS preflight проходит до установки Docker и Caddy и выдаёт ожидаемые результаты.
- [x] Fresh install запрашивает только утверждённые пользовательские поля и успешно запускает минимальный профиль.
- [x] Bot, Cabinet Mini App, PostgreSQL, Redis, Remnawave webhook, Caddy TLS и Telegram webhook проходят functional health.
- [x] Bot runtime подтверждён как non-root, а public ingress не открывает database, Redis или лишние backend routes.
- [x] Repeat install сохраняет настоящий pre-change recovery point и завершает транзакцию без потери данных.
- [x] Legacy configuration fixture мигрируется в minimal environment и advanced override без потери non-default values.
- [x] Settings draft остаётся неактивным до apply, показывает redacted plan и после apply отражается в observed runtime.
- [x] Compatible Release Bundle обновляется вместе с PostgreSQL protection и фиксированными schema revisions.
- [x] Injected failure после runtime mutation приводит к verified rollback либо ожидаемому safely stopped outcome с recovery plan.
- [x] File recovery возвращает проверенный runtime и не завершается ложным no-op из-за transient state.
- [x] Два Compose projects не конфликтуют при изолированной конфигурации.
- [x] Uninstall удаляет выбранный stack, но сохраняет management launcher и recovery tooling.
- [x] Test output сохраняет stage results и private diagnostic logs без раскрытия secrets.
- [x] Lifecycle scenario запускается как обязательный release gate installer и документирован для maintainers.
